## Discrepancies that matter

- **Claim 3 (Beckmeyer, Branger & Gayda 0DTE loss figure) is the one genuine population/period mismatch.** U1's $358,000/day and U2's $241,000/day are not the same statistic: $358,000/day is the average for the "since May 2022" (post daily-expiry-introduction) subsample, while $241,000/day is the whole-sample average for the longer, revised Feb 2021–Sept 2023 window in the paper's later (Dec 2023) revision. A downstream reader combining or comparing these two numbers as if they measured the same population/period would overstate or understate the loss rate depending on which one is used, and neither file discloses that the other number exists in the same paper. If a single "headline" 0DTE retail-loss figure is needed going forward, it should be tagged explicitly with which window it covers (whole-sample vs. post-May-2022 subsample) and which paper version it comes from.
- **Claim 12 (FPFX Technology prop-firm dataset) is unaudited, single-vendor data relayed through trade press, not an independent or regulator-verified industry census.** The specific figures (14% pass / 45% of passers paid / 4% of plan size / $800 average spend) are accurately transcribed in U2, but any conclusion in the wider report that leans on this as a "hard" industry base rate should be flagged as resting on one company's proprietary numbers as reported by a single trade publication, not as an audited statistic. U2's own file already carries a similar caveat, but it's worth restating given this is the source underlying the entire Section 3 EV-arithmetic in U2.
- **Claim 12's dating is wrong but immaterial to the number itself:** U2's source table lists the year as "2025/2026" for the Finance Magnates/FPFX article; it was actually published September 18, 2024. This doesn't change the substance of the figures, but it would mislead anyone trying to gauge how current/stale the dataset is (a 2024 snapshot, not a 2025/2026 one).
- **No other claim among the twelve, nor the negative CFTC claim, showed a material number, population, or period discrepancy from fresh search.** All other figures were independently reproduced with the same numbers, populations, and periods as quoted in U1/U2.

## Items where the two files disagree with each other

- **The Beckmeyer/Branger/Gayda 0DTE daily-loss figure (Claim 3)** is the only case where U1 and U2 report different headline numbers for what looks like the same underlying study: U1 uses $358,000/day (since May 2022), U2 uses $241,000/day (Feb 2021–Sept 2023). Both are real and correctly sourced to the same paper, but they describe different windows within it (see above) — this is a disagreement in which statistic to headline, not a factual error by either file.
- **No other overlapping claim (Heimer & Simsek leverage cap; ESMA/FCA CFD loss rates; Odean 1998 disposition effect; Barber-Huang-Odean-Schwarz Robinhood −4.7%) showed any numeric disagreement between U1 and U2** — where both files cite the same source, the numbers match each other as well as fresh search (Heimer & Simsek is stated slightly more completely in U2, which adds the "18 percentage points per month" clause U1 omits, but the two are consistent, not contradictory).
